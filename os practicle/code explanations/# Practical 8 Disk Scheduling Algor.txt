## Aim
To implement Disk Scheduling Algorithms such as SSTF, SCAN and C-LOOK in C and calculate the total head movement for each algorithm.

## Theory

Disk Scheduling is a technique used by the operating system to decide the order in which disk read and write requests are processed.

A disk contains several tracks or cylinders. The disk head moves to different positions to access the required data.

When multiple requests are waiting, the operating system uses disk scheduling algorithms to decide which request should be served first.

The main objective of disk scheduling is to reduce head movement and improve disk performance.

## Important Terms

1. **Disk Head:** The part of the disk system that reads and writes data.

2. **Track/Cylinder:** A circular path on the disk where data is stored.

3. **Head Position:** The current position of the disk head.

4. **Request Sequence:** The list of disk positions requested by processes.

5. **Head Movement:** The distance travelled by the disk head to serve requests.

6. **Total Head Movement:** The sum of all movements made by the disk head.

## Disk Scheduling Algorithms

### 1. SSTF (Shortest Seek Time First)

- SSTF selects the request that is closest to the current head position.
- It serves the nearest request first.
- After completing one request, it searches for the next nearest request.
- It reduces head movement compared to FCFS.
- It may cause starvation for requests that are far away.

### 2. SCAN Algorithm

- SCAN is also called the Elevator Algorithm.
- The disk head moves in one direction and serves all requests on its path.
- After reaching the end of the disk, it reverses its direction.
- It then serves the remaining requests in the opposite direction.
- It provides more predictable service than SSTF.

### 3. C-LOOK Algorithm

- C-LOOK stands for Circular LOOK.
- The disk head moves in one direction and serves all requests in that direction.
- After reaching the last request in that direction, it jumps to the first pending request on the other side.
- It does not travel to the physical end of the disk unless a request is present there.
- It then continues serving requests in the same direction.

2. It accepts the disk request sequence and stores it in an array.

This function implements the Shortest Seek Time First algorithm.

```c
int v[20] = {0}, t = 0, min, k = 0;
```

- `v[]` keeps track of completed requests.
- `t` stores total head movement.
- `min` stores the minimum distance.
- `k` stores the index of the nearest request.


Checks whether the request is not completed and is closer to the current head position than the previously selected request.

```c

t += abs(h - a[k]);
h = a[k];
```

- Marks the selected request as completed.
- Adds its movement distance to the total.
- Updates the current head position.

Finally, it displays the request sequence and total head movement.

### 3. SCAN Function

```c
void SCAN(int h, int size)
```

This function implements the SCAN disk scheduling algorithm.

```c
int b[20], t = 0, i, j, x;
```

- `b[]` stores a copy of the requests.
- `t` stores total head movement.
- `i` and `j` are loop variables.
- `x` is used for swapping values.

```c
b[n] = h;
```

Adds the initial head position to the copied request array so that it can be located after sorting.

The nested loops sort the request positions in ascending order.

```c
for (i = 0; i <= n && b[i] != h; i++);
```

Finds the position of the initial head in the sorted array.

The algorithm then:

1. Serves requests greater than the initial head position.
2. Moves to the last cylinder of the disk.
3. Reverses direction.
4. Serves the remaining requests.

```c
t += size - 1 - h;
h = size - 1;
```

Calculates the movement required to reach the last cylinder of the disk.

### 4. C-LOOK Function

```c
void CLOOK(int h)
```

This function implements the Circular LOOK algorithm.

```c
int b[20], t = 0, i, j, x, p = n;
```

- `b[]` stores the copied request sequence.
- `t` stores total head movement.
- `p` stores the index of the first request greater than or equal to the initial head position.

The nested loops sort the requests in ascending order.

```c
if (b[i] >= h)
{
    p = i;
    break;
}
```

Finds the first request at or above the initial head position.

The first loop serves requests from that position towards the largest request.

The second loop jumps to the smallest pending request and serves the remaining requests.

The total head movement is calculated and displayed.

Disk Scheduling is a technique used by the operating system to decide the order of disk requests.

**Q2. What is the main purpose of Disk Scheduling?**

To reduce disk head movement and improve performance.

**Q3. What is SSTF?**

SSTF stands for Shortest Seek Time First. It selects the request closest to the current head position.

**Q4. What is SCAN?**

SCAN is a disk scheduling algorithm in which the head moves in one direction, serves requests and then reverses direction.

**Q5. What is another name for SCAN?**

Elevator Algorithm.

**Q6. What is C-LOOK?**

C-LOOK is a circular disk scheduling algorithm that serves requests in one direction and then jumps to the first pending request on the other side.

**Q7. What is Seek Time?**

Seek Time is the time required for the disk head to move to the required track.

**Q8. What is Head Movement?**

It is the distance travelled by the disk head between two positions.

**Q9. What is starvation in SSTF?**

Starvation occurs when a request keeps waiting because nearer requests are repeatedly selected.

**Q10. What is the difference between SCAN and C-LOOK?**

SCAN moves to the physical end of the disk before reversing direction, while C-LOOK jumps from the last pending request to the first pending request.

**Q11. What is the use of `abs()`?**

It returns the absolute (positive) value of a number and helps calculate head movement.

**Q12. What is the use of the `v[]` array in SSTF?**

It keeps track of which disk requests have already been completed.

**Q13. What is the use of the `t` variable?**

It stores the total head movement.
